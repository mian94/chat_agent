### 📚 **知识点讲解**

#### **1. Vue3项目初始化**
**React类比**：
```bash
# Vue3 (Vite)
npm create vite@latest frontend -- --template vue-ts

# React (Vite)
npm create vite@latest frontend -- --template react-ts
```

**关键配置**：
- **Vite**：下一代前端构建工具，比Webpack更快
- **TypeScript**：JavaScript的超集，提供类型系统
- **Element Plus**：Vue3 UI组件库，类似React的Ant Design

**面试题**：
**问题**：Vite相比Webpack有什么优势？
**答案**：Vite有三大优势：1）开发服务器启动快，利用浏览器原生ES模块，无需打包；2）热更新快，只更新修改的模块；3）构建速度快，使用Rollup打包。Webpack需要打包整个应用，启动慢，但生态更成熟。

#### **2. Express后端初始化**
**React类比**：
```javascript
// Express (Node.js)
const express = require('express')
const app = express()
app.use(cors())
app.use(express.json())

// 类似React中的API路由
app.get('/api/health', (req, res) => {
  res.json({ status: 'ok' })
})
```

**关键概念**：
- **中间件**：请求处理管道，按顺序执行
- **路由**：定义API端点，处理HTTP请求
- **CORS**：跨域资源共享，解决前后端分离的跨域问题

**面试题**：
**问题**：Express中间件的执行顺序是什么？
**答案**：Express中间件按app.use()顺序执行，从上到下。每个中间件通过next()传递给下一个。路由中间件匹配路径执行。错误处理中间件（4个参数）最后执行。

#### **3. TypeScript类型系统**
**React类比**：
```typescript
// TypeScript接口定义
interface User {
  id: string
  name: string
  email?: string // 可选属性
}

// 类似React PropTypes
User.propTypes = {
  id: PropTypes.string.isRequired,
  name: PropTypes.string.isRequired,
  email: PropTypes.string
}
```

**关键语法**：
- **interface**：定义对象结构，支持继承
- **type**：定义类型别名，支持联合类型
- **泛型**：类型参数化，提高代码复用性

**面试题**：
**问题**：interface和type有什么区别？
**答案**：interface可以重复声明自动合并，type不行；type可以定义联合类型、交叉类型、基本类型别名，interface不行；interface支持extends继承，type支持&交叉。

#### **4. Axios请求封装**
**React类比**：
```javascript
// Axios封装
const request = axios.create({
  baseURL: '/api',
  timeout: 30000
})

// 请求拦截器
request.interceptors.request.use(config => {
  // 添加token
  return config
})

// 响应拦截器
request.interceptors.response.use(response => {
  // 统一处理错误
  return response
})
```

**关键功能**：
- **拦截器**：统一处理请求和响应
- **错误处理**：网络错误、超时、状态码处理
- **类型安全**：泛型支持，自动类型推断

**面试题**：
**问题**：如何封装一个通用的API请求模块？
**答案**：封装步骤：1）创建axios实例配置baseURL和超时；2）添加请求拦截器处理token；3）添加响应拦截器处理错误和数据转换；4）定义具体API函数；5）导出request实例。

#### **5. Vue Router路由配置**
**React类比**：
```javascript
// Vue Router
const routes = [
  { path: '/', component: Home }
]
const router = createRouter({ history: createWebHistory(), routes })

// React Router
const router = createBrowserRouter([
  { path: '/', element: <Home /> }
])
```

**关键概念**：
- **路由模式**：Hash模式（#）和History模式（/）
- **懒加载**：`() => import('./views/Home.vue')`
- **导航守卫**：路由跳转前的钩子函数

**面试题**：
**问题**：Vue Router的导航守卫有哪些？
**答案**：有三种：全局守卫（beforeEach、afterEach）、路由独享守卫（beforeEnter）、组件内守卫（beforeRouteEnter等）。用于登录验证、权限控制、页面离开提醒等。

#### **6. Pinia状态管理**
**React类比**：
```javascript
// Pinia (Vue3)
const useChatStore = defineStore('chat', () => {
  const sessions = ref([])
  function createSession() { ... }
  return { sessions, createSession }
})

// Redux (React)
const chatSlice = createSlice({
  name: 'chat',
  initialState: { sessions: [] },
  reducers: {
    createSession(state) { ... }
  }

```

**关键特性**：
- **Composition API风格**：使用ref、computed定义状态
- **模块化**：每个Store独立，便于维护
- **TypeScript支持**：完美的类型推断

**面试题**：
**问题**：Pinia和Vuex有什么区别？
**答案**：Pinia是Vue3官方推荐，API更简洁（没有mutations），完美支持TypeScript，支持Composition API风格。Vuex是Vue2时代的状态管理库，需要mutations修改状态。

#### **7. CSS变量与主题管理**
**React类比**：

**关键用法**：

**面试题**：
**问题**：CSS变量相比预处理器变量有什么优势？
**答案**：CSS变量是原生浏览器支持，无需编译；可以动态修改，JavaScript直接操作；有继承性，子元素自动继承。预处理器变量编译后是静态值。

### 📚 **知识点讲解**

#### **1. SSE流式通信（Server-Sent Events）**
**React类比**：
```javascript
// React中使用fetch + ReadableStream
const response = await fetch('/api/chat', {
  method: 'POST',
  body: JSON.stringify(data)
})
const reader = response.body.getReader()
const decoder = new TextDecoder()

while (true) {
  const { done, value } = await reader.read()
  if (done) break
  const text = decoder.decode(value, { stream: true })
  // 处理流式数据
}
```

**关键概念**：
- **SSE vs WebSocket**：SSE单向通信，基于HTTP；WebSocket双向通信，需要协议升级
- **流式响应**：服务器分块发送数据，客户端逐块接收
- **多字节字符处理**：使用TextDecoder的stream模式避免截断

**面试题**：
**问题**：SSE和WebSocket有什么区别？
**答案**：SSE是单向通信，基于HTTP，适合服务器推送场景如实时通知；WebSocket是双向通信，需要协议升级，适合实时交互如在线游戏。SSE实现简单，自动重连；WebSocket功能更强大但复杂度更高。

#### **2. DeepSeek API集成**
**React类比**：
```javascript
// 类似OpenAI API调用
const response = await fetch('https://api.deepseek.com/chat/completions', {
```

**关键实现**：

**面试题**：
**问题**：如何设计一个好的系统Prompt？
**答案**：好的系统Prompt应包含：1）明确的角色定义；2）具体的职责描述；3）输出格式规范；4）约束条件。项目中为三种模式设计了不同Prompt，刷题模式强调出题和批改，问答模式强调通俗易懂，模拟面试模式强调真实感。

#### **3. IndexedDB本地存储**
**React类比**：
```javascript
// IndexedDB vs localStorage
// localStorage: 简单键值对，5MB限制
localStorage.setItem('key', JSON.stringify(data))

// IndexedDB: 结构化存储，大容量，支持索引
const request = indexedDB.open('database', 1)
request.onupgradeneeded = (event) => {
  const db = event.target.result
  db.createObjectStore('sessions', { keyPath: 'id' })
}
```

**关键特性**：
- **结构化存储**：支持复杂数据结构，类似数据库
- **索引查询**：可以按字段快速查询
- **事务处理**：保证数据一致性

**面试题**：
**问题**：IndexedDB和localStorage有什么区别？
**答案**：IndexedDB是结构化存储，支持索引和复杂查询，异步API，容量大；localStorage是简单键值对，同步API，容量小（5MB）。IndexedDB适合存储结构化数据如聊天记录；localStorage适合存储简单配置如token。

#### **4. Markdown渲染与代码高亮**
**React类比**：
```javascript
// React中使用react-markdown
import ReactMarkdown from 'react-markdown'
import { Prism as SyntaxHighlighter } from 'react-syntax-highlighter'

function MarkdownRenderer({ content }) {
  return (
    <ReactMarkdown
      components={{
        code({ node, inline, className, children, ...props }) {
          const match = /language-(\w+)/.exec(className || '')
          return !inline && match ? (
            <SyntaxHighlighter language={match[1]} PreTag="div">
              {String(children).replace(/\n$/, '')}
            </SyntaxHighlighter>
          ) : (
            <code className={className} {...props}>
              {children}
            </code>
          )
        }
      }}
    >
      {content}
    </ReactMarkdown>
  )
}
```

**关键实现**：
- **marked库**：Markdown解析器，支持自定义渲染器
- **highlight.js**：代码高亮库，支持多种语言
- **自定义渲染器**：处理代码块、行内代码、表格等

**面试题**：
**问题**：如何实现Markdown中的代码高亮？
**答案**：使用highlight.js库，配置marked的自定义渲染器。在code渲染器中，获取代码语言，调用hljs.highlight()高亮，返回HTML。项目中还处理了行内代码、表格、链接等自定义渲染。

#### **5. 模式管理与身份表明**
**React类比**：
```javascript
// React中的模式状态管理
const [currentMode, setCurrentMode] = useState('qa')
const [lastUsedMode, setLastUsedMode] = useState(null)

// 判断是否需要表明身份

  if (shouldIntroduce) {
    // 在系统Prompt中添加身份表明指令

```

**关键逻辑**：
- **模式切换**：用户可以选择三种辅导模式
- **身份表明**：切换模式后的首次回复表明身份

**面试题**：

## 📝 **常见问题解答**

### **Q1：Vue3和React的主要区别是什么？**
**A**：Vue3使用模板语法，React使用JSX；Vue3的响应式系统基于Proxy，React基于状态提升；Vue3官方推荐Pinia状态管理，React常用Redux或Context。

### **Q2：TypeScript在项目中的作用是什么？**
**A**：TypeScript提供静态类型检查，减少运行时错误；提供更好的代码提示和自动补全；支持接口定义，提高代码可维护性。

### **Q3：为什么选择SSE而不是WebSocket？**
**A**：聊天功能只需要服务器推送，SSE基于HTTP实现简单，自动重连；WebSocket适合双向实时交互，实现复杂度更高。

### **Q4：IndexedDB的使用场景是什么？**
**A**：适合存储结构化数据，如聊天记录、用户数据；容量大（几百MB），支持索引查询；异步API，不会阻塞主线程。
