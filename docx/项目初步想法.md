一、核心名词通俗区分（前端学生友好版，理清概念边界）
1. AI（人工智能）
广义：所有让机器模拟人类智能的技术统称。
狭义（你日常接触）：大语言模型 LLM（DeepSeek、豆包、通义千问）、文生图模型等基础大模型。
定位：原材料，只会单纯根据文本输出文字，没有自主规划、记忆、执行能力。
举例：你单独调用豆包 API，发一句 “帮我规划前端学习路线”，它只能一次性回答，不会记住你们之前的对话、不会分步完成任务、不会主动调用工具。
2. Agent（智能体）【你要做的核心产品】
定义：以大模型（AI）为大脑，额外套一套自主执行框架，能独立完成复杂多步骤任务的智能程序。
核心特征：能感知、记忆、思考、规划、调用工具、迭代纠错，不是一问一答。
和普通 AI 聊天机器人的边界：
普通对话 AI：单次问答，无长期记忆，不会拆分任务，不能操作外部工具；
Agent：可以自主拆解复杂目标、记住长期上下文、调用接口 / 工具完成动作、多轮自主循环直到任务完成。
3. AGI（通用人工智能）
定义：拥有和人类同等通用认知能力的人工智能，能无差别学会人类任意工作、自主理解所有领域任务。
现状：目前全球没有真正的 AGI 产品，所有大厂 Agent 都只是专用增强型大模型，属于弱 AI，达不到通用智能。
对你的意义：你做的聊天 Agent 完全不用考虑 AGI，不用追求全能，只聚焦你设定的场景即可。
4. 配套高频词汇补充
LLM 大语言模型：Agent 的 “大脑”，提供文字理解、推理能力（必须调用第三方 API，自己训练不现实）；
Prompt 提示词工程：给大脑下达规则，定义 Agent 性格、能力、任务格式；
记忆 Memory：Agent 存储对话、历史任务的模块（短期记忆 / 长期记忆）；
工具调用 Tool Use：Agent 自主调用外部功能，比如查天气、请求接口、读写文件、网页搜索；
规划 Planning：复杂任务自主拆分步骤（比如 “做一份前端面试刷题计划” 自动拆：1. 收集高频八股 2. 按难度分类 3. 生成每日计划表）；
RAG 检索增强：给 Agent 接入私有知识库（你的前端笔记、八股文档），回答不依赖模型原生知识。

二、一个基础聊天 Agent 必备核心模块（前端学生可落地，最低配置）
模块 1：前端交互层（你的主业，重点写）
聊天对话框 UI：消息气泡、输入框、发送按钮、加载动画；
配置面板：切换模型（DeepSeek / 豆包）、开启记忆、开启联网搜索、调整 Agent 角色；
历史会话侧边栏：保存多轮对话记录；
工具可视化面板：Agent 调用工具时展示执行过程（比如 “正在搜索 Vue3 面试题”）。
技术栈：Vue3/React + TS + ElementPlus/Ant Design，本地存储用 LocalStorage/IndexedDB 存短期记忆。
模块 2：记忆系统（区分两种，缺一不可）
短期记忆（上下文窗口）
每次请求大模型时，带上本轮全部对话，让 AI 知道当前聊天上下文；
边界：大模型有上下文长度限制（比如 8k 上下文，太长会截断）。
长期记忆（知识库）
持久化存储历史对话、用户偏好、用户上传的文档（你的前端八股、笔记）；
技术：简易版直接存 IndexedDB；进阶版接入轻量向量库（MiniMax Embedding + 本地向量库 Vectra）做 RAG。
模块 3：核心 Agent 调度逻辑（中间层，前端可写 Node.js 服务）
这是区分普通聊天机器人和 Agent 的关键，4 个核心流程循环：
感知：接收用户输入，读取用户长期记忆；
规划：大模型自主判断任务复杂度，拆分多步执行；
工具判断：模型自主决定是否需要调用外部工具（搜索、查文档、计算器）；
反思迭代：工具执行完把结果丢回模型，模型整合信息再输出最终回答，任务没完成则继续循环。
模块 4：工具调用插件系统（Agent 灵魂）
没有工具 = 只是普通聊天框，不算 Agent。新手优先实现 3 个简易工具：
联网搜索工具：调用 SearXNG / 百度搜索 API，让 Agent 实时查前端新技术、面试题；
私有文档检索工具（RAG）：上传你的八股、项目笔记，Agent 回答时优先读取你的资料；
代码执行工具：运行前端 JS 代码，输出运行结果（适合前端刷题 Agent）。
模块 5：大模型 API 对接层
作为 Agent 大脑，直接调用国内商用 API（无需本地训练模型）：
可选：DeepSeek、火山引擎豆包、阿里云通义千问，全部提供免费额度，学生开发零成本。
模块 6：角色设定系统
通过系统 Prompt 定义 Agent 身份，比如「前端面试辅导 Agent」，固定能力边界：只解答前端八股、生成面试题、批改代码，不聊无关内容。
三、你的 Agent 清晰边界（避坑，知道什么能做、什么不用做）
1. 能力边界（你一个大三前端能实现的范围）
✅ 能做：
多轮记忆对话、自主拆分前端学习任务；
自动联网查询最新前端技术、面试真题；
读取你本地上传的八股 / 项目文档，针对性答疑；
自主调用工具、分步完成复杂需求（比如 “帮我准备 Vue 面试模拟，先出 10 道题，再批改我的回答，最后总结薄弱点”）；
完整前端可视化界面，本地存储所有聊天记录。
❌ 不用做、也做不到：
不用本地训练大模型（算力、资金门槛极高，学生完全没必要），只用 API 调用现成 LLM；
不用做机器人硬件、多模态视频 / 图片生成（聚焦文本聊天 Agent）；
不用追求 AGI 通用能力，限定场景：前端学习 / 面试辅导专用 Agent，场景越窄越好开发；
不用复杂分布式后端，一个 Node.js 单文件服务就能支撑全部逻辑。
2. 技术边界（降低开发难度）
前端只负责 UI 展示，Agent 调度、API 请求、工具调用全部放在 Node.js 中间层（跨域、密钥安全）；
向量库、数据库优先轻量本地方案，不用部署 MySQL、大型向量数据库；
不做线上公网部署，先完成本地单机可运行版本，作为课设 / 作品集。
3. 逻辑边界（区分 Agent 和普通对话机器人）
如果你的项目只有「输入文字→调用 LLM→返回文字」，只能叫 AI 聊天框，不能叫 Agent；
必须满足：存在自主工具调用、任务分步规划、长期记忆检索三者至少两个，才算标准 Agent。
四、分阶段落地步骤（大三前端学生零基础可跟着做，由简到难）
阶段 1：基础前置准备（1 天完成）
选定技术栈
前端：Vue3 + TS + Element Plus（上手快）
后端中间层：Node.js + Express
LLM API：DeepSeek（免费额度充足，工具调用能力强）
申请 API 密钥：DeepSeek 官网注册，获取免费调用额度；
搭建基础聊天页面：实现发送消息、展示对话、历史记录本地存储。
阶段 2：基础对话机器人（2-3 天，打底版本）
Node 层封装 LLM 请求接口，前端对接实现一问一答；
实现短期上下文记忆，每次对话携带历史消息；
增加系统 Prompt，固定 Agent 身份为「前端辅导智能体」。
此时：只是聊天机器人，还不属于 Agent。
阶段 3：添加 Agent 核心能力（核心阶段，3-5 天，升级为真正 Agent）
工具调用功能开发
给 LLM 传入工具描述 JSON，让模型自主判断什么时候需要搜索 / 查文档；
实现简易联网搜索工具、本地文档读取工具；
开发工具执行循环：模型要调用工具→后端执行工具→结果回传给模型→整合输出回答。
任务规划逻辑
写 Prompt 约束模型：复杂任务必须拆分步骤，分步执行，不能一次性输出答案。
长期记忆 RAG（加分项，作品集亮点）
接入轻量本地向量库，上传你的前端八股、项目笔记，Agent 提问时自动检索相关资料。
阶段 4：优化前端交互（2 天，提升作品集质感）
新增工具执行过程可视化（展示 Agent 思考、调用工具的步骤日志）；
会话管理、角色切换、参数配置面板；
美化 UI、增加代码块高亮、代码复制功能（适配前端场景）。
阶段 5：测试、修复边界问题（1 天）
测试超长对话上下文截断、工具调用失败兜底逻辑；
限制 Agent 能力，超出前端场景的问题拒绝回答，明确能力边界；
整理项目文档、演示录屏，作为实习 / 秋招前端作品集。
五、补充：适合你的 Agent 项目定位（前端学生最优选题）
项目名称：前端八股面试智能辅导 Agent
场景限定，开发难度低、求职含金量高：
记忆你的学习薄弱点，长期针对性出题；
自主联网抓取最新前端面试真题；
读取本地你的笔记、错题文档；
自主执行多轮模拟面试：出题→作答→批改→总结薄弱点→生成学习计划；
输出可运行 JS 代码，在线讲解代码逻辑。
这个项目完美结合你的前端专业，同时完整实现 Agent 全部核心特性，面试时可以清晰区分普通 AI 对话和 Agent 的差异，非常加分。
