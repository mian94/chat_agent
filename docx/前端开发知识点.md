## 1. 数据库总览

### 1.1 数据库分类

| 类型 | 代表数据库 | 数据模型 | 适用场景 |
|------|-----------|----------|----------|
| **关系型** | MySQL、PostgreSQL、SQLite | 表+行+列 | 结构化数据、事务处理、复杂查询 |
| **文档型** | MongoDB、CouchDB | 集合+文档（JSON/BSON） | 半结构化数据、快速迭代、灵活 schema |
| **键值型** | Redis、Memcached | Key-Value | 缓存、会话、排行榜、计数器 |
| **列族型** | Cassandra、HBase | 列族+行 | 大数据、时序数据、日志存储 |
| **图数据库** | Neo4j、ArangoDB | 节点+边 | 社交网络、推荐系统、知识图谱 |
| **浏览器本地** | IndexedDB、LocalStorage | Key-Value / 文档 | 前端离线存储、用户偏好、缓存 |

### 1.2 常用数据库详解

#### MySQL

- **概念**：最流行的关系型数据库，使用 SQL 查询语言
- **特点**：ACID 事务支持、成熟稳定、社区庞大
- **应用场景**：Web 应用后端、电商系统、CMS 内容管理
- **前端对接**：通过后端 API（Express + mysql2/pool）间接访问

#### MongoDB

- **概念**：文档型 NoSQL 数据库，存储 JSON-like 文档
- **特点**：灵活 schema、水平扩展、适合快速开发
- **应用场景**：内容管理、用户数据、日志分析、IoT 数据
- **前端对接**：通过后端 API（Express + mongoose）间接访问

#### Redis

- **概念**：内存键值数据库，支持多种数据结构（String、Hash、List、Set、Sorted Set）
- **特点**：极速读写（微秒级）、支持持久化、发布订阅
- **应用场景**：缓存、会话管理、排行榜、实时计数、消息队列
- **前端对接**：通过后端 API 间接访问

#### SQLite

- **概念**：轻量级嵌入式关系型数据库，整个数据库就是一个文件
- **特点**：零配置、无服务器、单文件存储
- **应用场景**：移动应用、桌面应用、小型 Web 应用、测试环境
- **前端对接**：可通过 sql.js 在浏览器中运行

#### IndexedDB

- **概念**：浏览器内置的 NoSQL 文档数据库
- **特点**：异步 API、大容量存储（几百 MB）、支持索引
- **应用场景**：前端离线存储、PWA 应用、大量数据缓存
- **本项目使用**：存储聊天记录、会话列表

### 1.3 数据库选型对比

| 维度 | MySQL | MongoDB | Redis | SQLite | IndexedDB |
|------|-------|---------|-------|--------|----------|
| **类型** | 关系型 | 文档型 | 键值型 | 关系型 | 文档型 |
| **存储位置** | 服务器 | 服务器 | 服务器（内存） | 本地文件 | 浏览器本地 |
| **查询语言** | SQL | MQL | Redis 命令 | SQL | JavaScript API |
| **事务支持** | ✅ 完整 | ✅ 有限 | ✅ 有限 | ✅ 完整 | ✅ 有限 |
| **扩展性** | 垂直扩展 | 水平扩展 | 水平扩展 | 无 | 无 |
| **性能** | 高 | 高 | 极高 | 中 | 中 |
| **适用规模** | 中大型 | 中大型 | 中大型 | 小型 | 小型 |

### 1.4 前端开发中接触的数据库

| 场景 | 数据库 | 访问方式 |
|------|--------|----------|
| 后端数据存储 | MySQL / MongoDB | 通过 API 间接访问 |
| 后端缓存 | Redis | 通过 API 间接访问 |
| 前端离线存储 | IndexedDB | 直接访问（浏览器 API） |
| 前端简单存储 | LocalStorage / SessionStorage | 直接访问（浏览器 API） |

### 1.5 LocalStorage vs SessionStorage vs IndexedDB

| 维度 | LocalStorage | SessionStorage | IndexedDB |
|------|--------------|----------------|----------|
| **容量** | 5-10 MB | 5-10 MB | 几百 MB |
| **生命周期** | 永久（手动清除） | 会话结束（标签页关闭） | 永久（手动清除） |
| **数据结构** | 字符串 | 字符串 | 任意 JS 对象 |
| **API** | 同步 | 同步 | 异步 |
| **索引** | ❌ | ❌ | ✅ |
| **适用场景** | 用户偏好、主题设置 | 表单临时数据 | 大量结构化数据 |

## 2. IndexedDB 本地数据库

### 2.1 原生 IndexedDB API

**IndexedDB** 是浏览器内置的 **NoSQL 数据库**，类似于 MongoDB，是文档型数据库。

| 对比 | MySQL | MongoDB | IndexedDB |
|------|-------|---------|-----------|
| 类型 | 关系型 | 文档型 | 文档型 |
| 存储位置 | 服务器 | 服务器 | **浏览器本地** |
| 查询语言 | SQL | MQL | JavaScript API |
| 数据结构 | 表+行 | 集合+文档 | 对象仓库+对象 |

**原生 API 示例**：

```javascript
// 打开数据库
const request = indexedDB.open('chatDB', 1);

// 创建对象仓库（类似 MongoDB 的集合）
request.onupgradeneeded = (event) => {
  const db = event.target.result;
  db.createObjectStore('messages', { keyPath: 'id' });
};

// 添加数据
request.onsuccess = (event) => {
  const db = event.target.result;
  const tx = db.transaction('messages', 'readwrite');
  const store = tx.objectStore('messages');
  
  store.add({ id: 1, content: '你好', role: 'user' });
};
```

**特点**：
- API 是**事件驱动**的，大量使用回调
- 代码冗长，嵌套层级深
- 没有 Promise 支持（原生）

---

### 2.2 idb 库

**idb** 是 Google Chrome 团队开发的轻量级库，对原生 IndexedDB API 的 **Promise 封装**。

类似于：
- **Mongoose** 对 **MongoDB 原生驱动** 的封装
- **Sequelize** 对 **MySQL 原生连接** 的封装

**idb 示例**：

```javascript
import { openDB } from 'idb';

// 打开数据库
const db = await openDB('chatDB', 1, {
  upgrade(db) {
    db.createObjectStore('messages', { keyPath: 'id' });
  },
});

// 添加数据
await db.add('messages', { id: 1, content: '你好', role: 'user' });

// 查询数据
const msg = await db.get('messages', 1);

// 获取所有数据
const allMessages = await db.getAll('messages');
```

---

### 2.3 核心区别

| 维度 | 原生 IndexedDB | idb 库 |
|------|---------------|--------|
| **语法** | 事件回调 | async/await |
| **代码量** | 多（嵌套回调） | 少（简洁） |
| **学习曲线** | 陡峭 | 平缓 |
| **体积** | 0（浏览器内置） | ~1.2KB |
| **类型支持** | 无 | TypeScript 支持 |
| **维护** | 浏览器厂商 | Google 团队 |

**代码对比**：

**原生 IndexedDB**（获取一条数据）：
```javascript
function getData(db, storeName, key) {
  return new Promise((resolve, reject) => {
    const tx = db.transaction(storeName, 'readonly');
    const store = tx.objectStore(storeName);
    const request = store.get(key);
    
    request.onsuccess = () => resolve(request.result);
    request.onerror = () => reject(request.error);
  });
}

const msg = await getData(db, 'messages', 1);
```

**idb**（同样功能）：
```javascript
const msg = await db.get('messages', 1);
```

#### Windows 系统

| 浏览器 | 路径 |
|--------|------|
| **Chrome** | `C:\Users\<用户名>\AppData\Local\Google\Chrome\User Data\Default\IndexedDB\` |


### 2.5 可视化工具

#### 最常用：浏览器 DevTools

**Chrome/Edge**：
1. 按 `F12` 打开 DevTools
2. 切换到 **Application** 标签
3. 左侧找到 **IndexedDB**
4. 可以查看、编辑、删除数据

```
Application
├── Storage
│   ├── IndexedDB
│   │   └── chatDB
│   │       ├── messages
│   │       │   ├── { id: 1, content: "你好", role: "user" }
│   │       │   └── { id: 2, content: "你好！有什么...", role: "assistant" }
│   │       └── sessions
│   │           └── ...
```

**Firefox**：
1. 按 `F12` 打开 DevTools
2. 切换到 **Storage** 标签
3. 找到 **IndexedDB**

#### 第三方工具

| 工具 | 说明 |
|------|------|
| **IndexedDB Viewer** | Chrome 扩展，独立窗口查看 |
| **IndexedDB Manager** | Firefox 扩展 |
| **PouchDB Inspector** | 专门用于 PouchDB（基于 IndexedDB） |

#### 与 DataGrip 对比

| 功能 | DataGrip | DevTools IndexedDB |
|------|----------|-------------------|
| 连接数据库 | ✅ | ❌（直接读浏览器数据） |
| SQL 查询 | ✅ | ❌（只能点击浏览） |
| 数据编辑 | ✅ | ✅ |
| 导出数据 | ✅ | ✅（JSON） |
| 表结构设计 | ✅ | ❌ |

**结论**：IndexedDB 没有像 DataGrip 那样强大的独立工具，但浏览器 DevTools 已经足够日常开发使用。

### 2.7 项目中的使用建议

根据项目技术栈（Vue3 + TypeScript），推荐：

```typescript
// src/utils/db.ts
import { openDB, type IDBPDatabase } from 'idb';

interface ChatDB {
  messages: {
    key: string;
    value: {
      id: string;
      role: 'user' | 'assistant';
      content: string;
      timestamp: number;
    };
  };
  sessions: {
    key: string;
    value: {
      id: string;
      title: string;
      mode: string;
      createdAt: number;
    };
  };
}

let dbPromise: Promise<IDBPDatabase<ChatDB>>;

export function getDB() {
  if (!dbPromise) {
    dbPromise = openDB<ChatDB>('chat-agent', 1, {
      upgrade(db) {
        db.createObjectStore('messages', { keyPath: 'id' });
        db.createObjectStore('sessions', { keyPath: 'id' });
      },
    });
  }
  return dbPromise;
}

// 使用示例
async function saveMessage(msg: ChatDB['messages']['value']) {
  const db = await getDB();
  await db.put('messages', msg);
}

async function getMessages(sessionId: string) {
  const db = await getDB();
  const all = await db.getAll('messages');
  return all.filter(m => m.id.startsWith(sessionId));
}
```
